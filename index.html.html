LECTURE 01

Introduction to C++

💡
What is C++?
History, purpose, and why learn it
+

C++ is a powerful, general-purpose programming language created by Bjarne Stroustrup in 1979 as an extension of C. It supports both procedural and object-oriented programming, making it one of the most versatile languages ever created.

C++ is used in: game engines, operating systems, browsers, embedded systems, and competitive programming. Knowing C++ gives you a deep understanding of how computers actually work.

Paradigm
Multi-paradigm (OOP + Procedural)
Speed
Compiled — extremely fast
Created by
Bjarne Stroustrup, 1979
Extension of
C Language
💡 Tip: C++ gives you control over memory. This power means more responsibility — but also more performance.
LECTURE 02

Program Structure

🏗️
Anatomy of a C++ Program
Headers, main(), and return statements
+

Every C++ program has a specific structure. Let's break down the simplest possible program — the famous "Hello, World!"

C++
#include <iostream>    // Include standard I/O library
using namespace std;    // Use standard namespace

int main() {           // Entry point of every C++ program

    cout << "Hello, World!" << endl;

    return 0;           // 0 means success
}
Output
Hello, World!

#include <iostream> — Brings in the library for input/output.
using namespace std; — Lets us write cout instead of std::cout.
int main() — The function where execution begins.
return 0; — Signals the OS that the program ran successfully.

LECTURE 03

Variables & Data Types

📦
Declaring Variables
int, float, double, char, bool, string
+

A variable is a named container that stores data. In C++, you must specify the data type before the variable name.

C++
#include <iostream>
#include <string>
using namespace std;

int main() {
    int    age     = 21;          // whole number
    float  gpa     = 3.75f;       // decimal (4 bytes)
    double salary  = 85000.50;   // decimal (8 bytes, more precise)
    char   grade   = 'A';         // single character
    bool   passed  = true;        // true or false
    string name    = "Niazi";     // text

    cout << "Name: "   << name   << endl;
    cout << "Age: "    << age    << endl;
    cout << "GPA: "    << gpa    << endl;
    cout << "Passed: " << boolalpha << passed << endl;

    return 0;
}
Output
Name: Niazi
Age: 21
GPA: 3.75
Passed: true
int
−2B to 2B whole numbers
float
~7 decimal digits
double
~15 decimal digits
char
Single character 'A'
bool
true or false only
string
Sequence of characters
LECTURE 04

Input & Output

⌨️
cout and cin
Printing to screen and reading from keyboard
+

cout (Character Output) prints data to the screen using the << operator. cin (Character Input) reads data from the keyboard using the >> operator.

C++
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age;

    cout << "Enter your name: ";
    cin  >> name;

    cout << "Enter your age: ";
    cin  >> age;

    cout << "Hello, " << name
         << "! You are " << age << " years old." << endl;

    return 0;
}
Sample Run
Enter your name: Niazi
Enter your age: 22
Hello, Niazi! You are 22 years old.
💡 Tip: Use getline(cin, variable) to read a full sentence with spaces instead of just one word.
LECTURE 05

Operators

➕
Arithmetic, Relational & Logical
All operator types with examples
+
C++
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;

    // ── Arithmetic Operators ──
    cout << a + b  << endl; // 13  (Addition)
    cout << a - b  << endl; // 7   (Subtraction)
    cout << a * b  << endl; // 30  (Multiplication)
    cout << a / b  << endl; // 3   (Integer division)
    cout << a % b  << endl; // 1   (Modulo / remainder)

    // ── Relational Operators ──
    cout << (a > b)  << endl; // 1 (true)
    cout << (a == b) << endl; // 0 (false)
    cout << (a != b) << endl; // 1 (true)

    // ── Logical Operators ──
    cout << (a>5 && b<5)  << endl; // 1 (AND: both true)
    cout << (a<5 || b<5)  << endl; // 1 (OR: one is true)
    cout << !(a==b)            << endl; // 1 (NOT)

    return 0;
}
LECTURE 06

Conditions — if / else

🔀
if, else if, else
Making decisions in your program
+

Conditional statements let your program make decisions. The code inside an if block only runs when the condition is true.

C++
#include <iostream>
using namespace std;

int main() {
    int marks;
    cout << "Enter your marks: ";
    cin  >> marks;

    if (marks >= 90) {
        cout << "Grade: A+" << endl;
    } else if (marks >= 80) {
        cout << "Grade: A" << endl;
    } else if (marks >= 70) {
        cout << "Grade: B" << endl;
    } else if (marks >= 50) {
        cout << "Grade: C" << endl;
    } else {
        cout << "Grade: Fail" << endl;
    }

    return 0;
}
Sample Run (marks = 85)
Enter your marks: 85
Grade: A
LECTURE 07

Switch Statement

🎛️
switch / case / break / default
Cleaner multi-branch decisions
+

switch is cleaner than many if-else chains when you're comparing one variable against multiple fixed values.

C++
#include <iostream>
using namespace std;

int main() {
    int day;
    cout << "Enter day number (1-7): ";
    cin  >> day;

    switch (day) {
        case 1: cout << "Monday";    break;
        case 2: cout << "Tuesday";   break;
        case 3: cout << "Wednesday"; break;
        case 4: cout << "Thursday";  break;
        case 5: cout << "Friday";    break;
        case 6: cout << "Saturday";  break;
        case 7: cout << "Sunday";    break;
        default: cout << "Invalid!";
    }

    cout << endl;
    return 0;
}
⚠️ Important: Always add break; after each case, or execution will "fall through" to the next case.
LECTURE 08

Loops

🔄
for Loop
Repeat a fixed number of times
+

The for loop is best when you know exactly how many times you want to repeat something. It has 3 parts: init, condition, and update.

C++
#include <iostream>
using namespace std;

int main() {
    // Print numbers 1 to 5
    for (int i = 1; i <= 5; i++) {
        cout << "Iteration " << i << endl;
    }

    // Multiplication table of 3
    cout << "\nTable of 3:" << endl;
    for (int i = 1; i <= 10; i++) {
        cout << "3 x " << i << " = " << 3*i << endl;
    }
    return 0;
}
🔁
while & do-while Loops
Repeat while a condition is true
+
C++
#include <iostream>
using namespace std;

int main() {
    // while loop — checks BEFORE executing
    int count = 1;
    while (count <= 3) {
        cout << "while: " << count++ << endl;
    }

    // do-while — executes AT LEAST ONCE
    int n;
    do {
        cout << "Enter a positive number: ";
        cin >> n;
    } while (n <= 0);

    cout << "You entered: " << n << endl;
    return 0;
}
💡 Rule: Use for when count is known. Use while when count depends on a condition. Use do-while when you need at least one execution.
LECTURE 09

Functions

⚙️
Defining & Calling Functions
Parameters, return types, and reusable code
+

A function is a reusable block of code with a name. Functions help you avoid repetition and organize your code into logical pieces.

C++
#include <iostream>
using namespace std;

// Function with no parameters and no return
void greet() {
    cout << "Hello from Niazi's C++ Course!" << endl;
}

// Function with parameters and return value
int add(int a, int b) {
    return a + b;
}

// Function to check if a number is even
bool isEven(int n) {
    return (n % 2 == 0);
}

int main() {
    greet();

    int sum = add(7, 3);
    cout << "7 + 3 = " << sum << endl;

    cout << "10 is even: " << boolalpha << isEven(10) << endl;
    cout << "7 is even: "  << boolalpha << isEven(7)  << endl;

    return 0;
}
Output
Hello from Niazi's C++ Course!
7 + 3 = 10
10 is even: true
7 is even: false
LECTURE 10

Arrays

🗂️
1D Arrays — Basics
Declaring, initializing, and accessing arrays
+

An array is a collection of variables of the same type stored in consecutive memory locations. Instead of declaring 100 separate variables, you use one array.

C++
#include <iostream>
using namespace std;

int main() {
    // Declare array of 5 integers
    int scores[5] = {90, 85, 78, 92, 88};

    // Access individual elements (index starts at 0)
    cout << "First score:  " << scores[0] << endl;
    cout << "Third score:  " << scores[2] << endl;
    cout << "Last score:   " << scores[4] << endl;

    // Print all elements using for loop
    cout << "\nAll scores:" << endl;
    for (int i = 0; i < 5; i++) {
        cout << "scores[" << i << "] = " << scores[i] << endl;
    }

    return 0;
}
Output
First score: 90
Third score: 78
Last score: 88

All scores:
scores[0] = 90
scores[1] = 85
scores[2] = 78
scores[3] = 92
scores[4] = 88
📊
Array Operations
Sum, average, min, max using arrays
+
C++
#include <iostream>
using namespace std;

int main() {
    int nums[6] = {12, 45, 7, 89, 3, 56};
    int size = 6;

    int sum = 0, minVal = nums[0], maxVal = nums[0];

    for (int i = 0; i < size; i++) {
        sum += nums[i];
        if (nums[i] < minVal) minVal = nums[i];
        if (nums[i] > maxVal) maxVal = nums[i];
    }

    cout << "Sum:     " << sum << endl;
    cout << "Average: " << (double)sum/size << endl;
    cout << "Minimum: " << minVal << endl;
    cout << "Maximum: " << maxVal << endl;

    return 0;
}
Output
Sum: 212
Average: 35.3333
Minimum: 3
Maximum: 89
🧮
2D Arrays
Arrays of arrays — rows and columns
+

A 2D array is like a table with rows and columns. Access elements with two indices: array[row][column].

C++
#include <iostream>
using namespace std;

int main() {
    // 3x3 matrix
    int matrix[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    cout << "Matrix:" << endl;
    for (int row = 0; row < 3; row++) {
        for (int col = 0; col < 3; col++) {
            cout << matrix[row][col] << " ";
        }
        cout << endl;
    }
    return 0;
}
Output
Matrix:
1 2 3
4 5 6
7 8 9
💡 Real-world use: 2D arrays are used for game boards, image pixels, spreadsheets, and mathematical matrices.
